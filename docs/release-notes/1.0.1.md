# Island Note 1.0.1 (build 9)

## What's New · English

Fixes a freeze and lost saves after the note file or its folder was moved or renamed. Island Note now follows the moved note, and if it can't be found, it tells you how to choose it again.

## 新功能 · 简体中文

修复了笔记文件或所在文件夹被移动、重命名后，Island Note 卡住、无法保存的问题。现在会自动跟随移动后的笔记；如果找不到，会提示你重新选择。
