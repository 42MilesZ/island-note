# Island Note 1.0.1 (build 13)

## What's New · English

Fixes a freeze and lost saves after the note file or its folder was moved or renamed. Island Note follows the moved note, recreates a missing note at its saved location and keeps your save location across updates. Reopening it from Finder or Spotlight brings the note forward.

The island now fits your Mac's notch. On displays without a notch, hover over the top centre of the screen to show it.

Resize notes from any corner, double-click the header to dock a floating note, change the save location from the editor's menu, and use standard ⌘ text shortcuts. New installs start with a short guide note.

## 新功能 · 简体中文

修复了笔记文件或所在文件夹被移动、重命名后卡住、无法保存的问题。现在会跟随移动后的笔记，文件缺失时在原位置重建，更新后保留保存位置；从访达或 Spotlight 再次打开会唤出笔记。

灵动岛现在会贴合 Mac 的刘海。在没有刘海的显示器上，鼠标移到屏幕顶部中间即可唤出。

现在可以拖动任意一角调整笔记大小，双击标题栏让浮动笔记收回灵动岛，在编辑器右键菜单中更改保存位置，并支持 ⌘ 方向键等标准文本快捷键。新安装会附带一篇简短的入门笔记。
