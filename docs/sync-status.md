# 保存与同步状态契约

状态控件的点、文字和展开规则由 `StatusPresentation` 统一映射。右边缘固定，点在左、文字在右；点前 12 pt、点与文字间 4 pt、文字后 11 pt。最窄 320 pt 面板仍保留至少 20 pt 拖动区域。拖拽条高 30 pt；状态控件的 hover 热区四周扩展 6 pt，放在父视图上跟踪，不裁切到按钮边界。扩展热区也排除边缘缩放，避免出现缩放光标；按钮视觉尺寸保持 24 pt。

| 条件 | 颜色 | 自动展开文案 |
| --- | --- | --- |
| 当前版本已写入磁盘，Flomo 已验证相同版本 | 绿色 | 无 |
| Flomo 扩展关闭，当前版本已写入磁盘 | 绿色 | 无 |
| 读取、待保存、待同步、限流、输入引起的重试 | 灰色 | 无 |
| 未连接、暂停、明确离线 | 灰色 | 无 |
| 后台只读检查 | 浅灰色呼吸 | 无 |
| 实际上传、回读验证或保存远端修改 | 浅灰色呼吸 | “正在同步…” |
| 两端修改冲突或初次连接的不同内容 | 橙色 | “有冲突” |
| 回读内容与上传内容不一致 | 橙色 | “内容不一致” |
| 写入响应丢失、创建结果不明 | 橙色 | “同步未确认”／“创建未确认” |
| 授权、格式、长度、连接或其他同步错误 | 橙色 | 对应原因 |
| 本地读取或保存失败 | 红色 | “未保存”，优先于任何同步状态 |

新输入立即离开已同步状态。中文输入法的组字阶段暂未发布到文本绑定时，也显示待保存；保留原生输入法委托。本地保存回调只确认磁盘写入，不恢复旧的云端成功状态；只有后续同步验证当前版本，才能恢复已同步。

`reviewPhase` 独立持久化未解决的差异，不被检查、网络错误或暂停覆盖。旧记录的写入／创建／合并意图会恢复相应警告。点击差异先读取最新两份内容，不自动上传或拉取；暂停时允许查看已有比较，替换按钮禁用。明确选择替换或合并时仍重新核对两端版本。

冲突对照使用独立、可缩放的非模态窗口。左侧为 Island Note，右侧为 Flomo，各自的“保留这份”固定在该栏下方，并标明将更新的另一端；底部保留“保留两份”和“稍后处理”。暂停时合并入口替换为“恢复同步”；设置的“更多 Flomo 选项”也可暂停或恢复。合并仍按本地、Flomo 的顺序追加到同一条笔记，不去重，存在未确认写入时禁用合并。

打开设置或同步确认窗口时，笔记先保存待处理编辑并收起；浮动笔记使用原有回岛收起过程。窗口打开不再阻止鼠标离开触发的收起，也不会取消已经排队的收起。弹窗期间只暂停悬停／点击重新展开，关闭后恢复正常入口，不主动展开笔记。普通浮动笔记仍不会因鼠标离开而收起。

每栏显示对应版本的更新时间及字符数：本地时间读取文件修改时间，远端时间读取该次 fetch 的 `updated_at`。带时区的远端时间转换为本机时间；不带时区的返回值保留原文，无法读取则明确显示未知，不拿同步时间替代。页头分别显示最近验证同步时间和该组对照的读取时间。刷新失败保留旧对照，并独立显示失败原因；选择前仍重新读取、比较原始内容与远端版本。最新两份已等价时，只读复核会解除旧的冲突提示。

对照正文使用可选择的 14 pt 系统字体与两个独立原生滚动区。首次显示前完成 TextKit 排版，滚动时不重建 Markdown 预览或修改内容高度；正文宽度随视口变化，按钮和时间保持固定。`SyncReview` 日志仅记录排版耗时，不记录正文。

每次更新前另外持久化该次远端内容基准与版本号。响应丢失后，只有重新读取的远端版本号和内容均未改变，才清除未生效的写入意图并重新走正常的条件同步；远端版本改变或旧记录缺少证据时仍需复核。若当前两份内容已相同，旧的未确认写入可由只读比较解除。普通段落的 1–3 个段首空格可视为排版差异；列表嵌套、列表续行、四空格缩进、硬换行及真实文字变化仍保留差异。

只有 `URLError.notConnectedToInternet` 证明离线；超时和服务错误不标成离线。握手失败能证明写入未发送。写入请求发出后的丢失响应保留意图，先回读核验；后续读取失败不能清除旧意图。发送前持久化失败回滚本次意图，拒绝或发送前取消只恢复该操作之前的意图。

后台同步在启动、每 60 秒轮询、本地保存后静置 3 秒触发；面板展开和悬停只改变展示，不发起同步；展开时发现磁盘上的真实外部修改，则沿用静置 3 秒后的同步规则。日志记录触发来源及状态，不记录笔记正文或令牌。

只读检查不自动展开；实际传输立即展开。所有状态点带同色柔光，成功使用明亮绿色。展开底色跟随状态文字的颜色，不透明度 10%，悬停增至 18%，按下增至 24%。悬停和按下只改变底色，不改变文字、宽度或展开状态，不显示“点击查看”等操作提示；完整状态保留在辅助功能描述和点击后的窗口中。气泡整块可见范围使用原生按钮的按下、松开与拖出取消规则；额外 6 pt 只用于悬停。底色、文字、小点和光晕的颜色均以 0.24 秒 Ease In Out 过渡。实际状态变化时，宽度、位置、文字、颜色使用显式 Ease In Out，从当前 presentation 状态接续；旧文字独立淡出。减少动态设置变化时立即停止呼吸，保留短反馈。
