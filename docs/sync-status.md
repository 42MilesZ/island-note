# 保存与同步状态契约

状态控件的点、文字和展开规则由 `StatusPresentation` 统一映射。右边缘固定，点在左、文字在右；点前 12 pt、点与文字间 4 pt、文字后 11 pt。最窄 320 pt 面板仍保留至少 20 pt 拖动区域。

| 条件 | 颜色 | 自动展开文案 |
| --- | --- | --- |
| 当前版本已写入磁盘，Flomo 已验证相同版本 | 绿色 | 无；悬停显示“已保存 · 已同步” |
| Flomo 扩展关闭，当前版本已写入磁盘 | 绿色 | 无；悬停显示“已保存到本机” |
| 读取、待保存、待同步、限流、输入引起的重试 | 灰色 | 无；悬停说明当前状态 |
| 未连接、暂停、明确离线 | 灰色 | 无；悬停区分原因 |
| 后台只读检查 | 浅灰色呼吸 | 无；悬停显示检查状态 |
| 实际上传、回读验证或保存远端修改 | 浅灰色呼吸 | “正在同步…” |
| 两端修改冲突或初次连接的不同内容 | 橙色 | “有冲突” |
| 回读内容与上传内容不一致 | 橙色 | “内容不一致” |
| 写入响应丢失、创建结果不明 | 橙色 | “同步未确认”／“创建未确认” |
| 授权、格式、长度、连接或其他同步错误 | 橙色 | 对应原因 |
| 本地读取或保存失败 | 红色 | “未保存”，优先于任何同步状态 |

新输入立即离开已同步状态。中文输入法的组字阶段暂未发布到文本绑定时，也显示待保存；保留原生输入法委托。本地保存回调只确认磁盘写入，不恢复旧的云端成功状态；只有后续同步验证当前版本，才能恢复已同步。

`reviewPhase` 独立持久化未解决的差异，不被检查、网络错误或暂停覆盖。旧记录的写入／创建／合并意图会恢复相应警告。点击差异先读取最新两份内容，不自动上传或拉取；暂停时允许查看已有比较，替换按钮禁用。明确选择替换或合并时仍重新核对两端版本。

只有 `URLError.notConnectedToInternet` 证明离线；超时和服务错误不标成离线。握手失败能证明写入未发送。写入请求发出后的丢失响应保留意图，先回读核验；后续读取失败不能清除旧意图。发送前持久化失败回滚本次意图，拒绝或发送前取消只恢复该操作之前的意图。

后台同步在启动、每 60 秒轮询、本地保存后静置 3 秒触发；面板展开和悬停只改变展示，不发起同步；展开时发现磁盘上的真实外部修改，则沿用静置 3 秒后的同步规则。日志记录触发来源及状态，不记录笔记正文或令牌。

只读检查不自动展开；实际传输立即展开。所有状态点带同色柔光，成功使用明亮绿色。展开底色跟随状态文字的颜色，不透明度 6%；底色、文字、小点和光晕的颜色均以 0.24 秒 Ease In Out 过渡。宽度、位置、文字、颜色使用显式 Ease In Out，从当前 presentation 状态接续；旧文字独立淡出。减少动态设置变化时立即停止呼吸，保留短反馈。

## 本地验证

覆盖状态矩阵、持续输入、上传时新增输入、后台轮询、冲突跨离线／暂停／重启、响应丢失后的只读恢复、条件写入拒绝、发送前取消／持久化失败、真实 URLSession 模拟离线与超时、协调写入失败、最窄面板中英文原生渲染、动画中间帧与快速反向、运行中开启减少动态。

本机 Command Line Tools 可编译应用，但当前 Xcode/XCTest 安装缺少可用的 Swift 测试覆盖层。相同关键用例通过链接实际应用对象的独立 Swift 验收程序运行；这不等同于完整 XCTest 套件通过。
